# Roadmap

## Current public baseline

- Typed public API and CLI for `capabilities` and `demo`.
- Explicit dated research policy fixture.
- Decimal account posting, reconciliation, and quote arithmetic.
- Finite-volume transport and scikit-fem adapter tests.
- Optional Bayesian smoke test pathway.
- Public README assets, publication guard, CI workflow, and architecture/publication tests.

## Near term

1. Preserve a tiny, deterministic kernel with no hidden network calls.
2. Add richer examples that remain synthetic and finite-valued.
3. Keep policy fixtures explicitly dated and non-official.
4. Publish source/assumption registry templates for future validated policy providers.

## Medium term

1. Stable API/deprecation policy for downstream workbenches.
2. More transport oracle parity tests across discontinuous hazards.
3. Optional diagnostics wrappers for Bayesian smoke output.
4. Package-versioned JSON schemas for CLI outputs.

## Roadmap only

- International jurisdictions.
- Official current-law Chile rules.
- Real member records, banking/custody, live transfers, or operational AFP administration.

Those require separate legal, privacy, security, and actuarial governance before any public implementation.
